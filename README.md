# Коллекторы онлайн

Настольная игра «Коллекторы» (by Goliaf) для игры с друзьями через интернет.

## Из чего состоит

- `server.js`: небольшой сервер на Node.js без сторонних библиотек. Он отдаёт страницу игры и пересылает ходы между игроками.
- `public/index.html`: сама игра.
- `package.json`: описание для хостинга (команда запуска `npm start`).

Партию ведёт браузер того, кто создал стол. Сервер только соединяет игроков. Поэтому ему хватает самого маленького бесплатного тарифа.

## Как играть

1. Откройте адрес сервера, впишите имя, выберите число мест (2–4) и нажмите **«Создать стол»**. Появится код из 4 букв.
2. Нажмите **«Скопировать приглашение»** и отправьте ссылку друзьям. Можно просто продиктовать код.
3. Друзья открывают ссылку (или тот же адрес и вводят код) и нажимают **«Сесть за стол»**.
4. Вы нажимаете **«Начать партию»**. Пустые места займут боты.

Держите вкладку создателя стола открытой до конца партии. Если связь у друга оборвалась, он нажимает «Переподключиться» или заново вводит код и возвращается на своё место.

## Вариант А: бесплатно на Render (без своего компьютера)

Нужны аккаунты на GitHub и Render. Оба бесплатные, можно войти через Google.

1. **GitHub: создайте репозиторий**
   - Зайдите на github.com, нажмите **New repository**, назовите, например, `kollektory`, и нажмите **Create repository**.
   - На странице репозитория нажмите **uploading an existing file**.
   - Перетащите файлы `server.js`, `package.json`, `README.md` и папку `public` целиком (внутри `index.html`).
   - Нажмите **Commit changes**.
2. **Render: создайте сервис**
   - Зайдите на render.com, нажмите **New → Web Service** и подключите свой GitHub.
   - Выберите репозиторий `kollektory`.
   - Заполните настройки:
     - **Runtime:** Node
     - **Build Command:** `npm install`
     - **Start Command:** `npm start`
     - **Instance Type:** Free
   - Нажмите **Create Web Service** и подождите 1–2 минуты.
3. Вверху появится адрес вида `https://kollektory-xxxx.onrender.com`. Это и есть ваша игра, отправляйте его друзьям.

На бесплатном тарифе Render сервер «засыпает», если на нём 15 минут никто не играл. Первое открытие после перерыва занимает до минуты. Во время партии сервер не засыпает.

**Обновить игру:** загрузите новые файлы в тот же репозиторий на GitHub, и Render сам перезапустит сервер.

## Вариант Б: свой сервер (VPS) или домашний компьютер

Нужен Node.js версии 18 или новее.

```bash
cd kollektory-online
npm start            # игра откроется на http://localhost:3000
PORT=8080 npm start  # или на другом порту
```

С домашнего компьютера друзья по интернету так просто не подключатся. Нужен белый IP и проброс порта на роутере или туннель (например, `cloudflared tunnel --url http://localhost:3000`). На VPS достаточно открыть порт или поставить перед сервером nginx с HTTPS.

## Если что-то не работает

- **«Стол с таким кодом не найден».** Проверьте код и то, что вкладка создателя стола открыта.
- **«Игра открыта не с сервера».** Файл `index.html` открыт с диска. Для сетевой игры его нужно открывать по адресу сервера. Одному с ботами можно играть и так.
- **Сервер не отвечает на Render.** Подождите минуту: он просыпается. Проверить можно по адресу `…/health`, там должно быть `ok`.
